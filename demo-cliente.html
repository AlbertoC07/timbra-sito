Demo customer code

TimbraBusiness is the cashier app: it scans a code shown by a customer in the companion app, Timbra. This page shows a demo customer’s code so it can be scanned without installing the second app.

Cliente Demo

Demo customer · Pizzeria Demo

  1. Open TimbraBusiness and sign in with the credentials provided in App Store Connect.
  2. Tap “Scansiona il codice cliente” (Scan customer code).
  3. Point the camera at the code above.
  4. Choose how many stamps to assign and confirm. The customer card already holds 5 of 8 stamps.

This code contains only timbra:u:<user id>. It can be used solely by an authorised cashier of the locale it belongs to, and the demo account is limited to a demo locale with no real customers.
